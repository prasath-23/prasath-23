### 🚀 What I'm doing

I build backends for **multi-tenant SaaS in the logistics/TMS domain** — schema through API to UI, plus
the AWS infrastructure underneath. Day to day that's **C#/.NET Core, Java, Kotlin, T-SQL and Vue/Quasar**,
with **AWS (Lambda, EventBridge, S3, KMS), Terraform and Docker** on the delivery side.

Right now I'm an **Agent Builder in Aptean's Agent Engineering org**, working on the TOTALogistix TMS
product line: writing and iterating prompts, designing retrieval and reasoning logic, integrating
**MCP servers**, and running evaluations on every revision.

Outside work I build things that let me go deeper than the day job allows — an OAuth2/OIDC identity
platform in Go, an offline crypto app-locker in Kotlin, and a deep-learning model that reads ECGs.

### 📦 Projects

**[Alora Auth](https://github.com/prasath-23/Alora-Auth)** — B2B Login & SSO Platform · `Go · PostgreSQL · OAuth2 · JWT`
> Multi-tenant B2B authentication and SSO, engineered in Go. OAuth2 with PKCE (S256), Google SSO,
> RS256-only JWTs with key rotation, JWKS and an alg-confusion guard, Argon2id hashing with
> anti-enumeration, and refresh-token rotation with reuse detection and family revocation over
> row-locked transactions. Strict tenant isolation and RBAC, fail-closed CORS, rate limiting and an
> append-only audit log.

**[Krypt](https://github.com/prasath-23/Krypt)** — Offline P2P App Locker · `Kotlin · Android · Cryptography`
> Offline, peer-to-peer Android access control using symmetric-key cryptography and deep-link
> handshakes. A physical-presence "Guardian" onboarding protocol — the Guardian must hold the device
> to enter the PIN — removes remote-interception vectors with no network dependency at all.

**[Sleep Apnea Detection](https://github.com/prasath-23/Sleep-apnea-detection)** — ECG deep learning · `Python · TensorFlow · Flask`
> Detects obstructive sleep apnea from a single-lead ECG, minute by minute. A modified 1D LeNet-5
> reads five-minute windows of R-R intervals and R-peak amplitudes; a hybrid 1D-GoogLeNet + LSTM
> pushes it further. Served through a Flask API with real-time charting.
